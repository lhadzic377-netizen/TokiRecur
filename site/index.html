Toki Recur is drop-in prefix caching for local inference. Agents, shells, and services running against the same llama-server share one living KV cache — so a long system prompt, tool corpus, or project context is computed once and replayed from memory. No patches. No vendor lock-in. Just an OpenAI-compatible daemon in front of your model.

Install in 3 commands See measured results

⚡ Drop-in cache

Point any OpenAI-compatible client (opencode, OpenClaw, Hermes, your own) at the toki daemon. Prompts that start with a cached prefix return instantly.

🔄 Live reuse

Multiple agents and shells share one server's KV cache. Context written by one session is replayed by the next — no duplicate compute, no duplicate memory.

📦 Save & restore

Persist whole caches to disk and restore them later: cold-start a service with its long system prompt already cached, or hand a session to another machine.

🛡️ RAM-aware by default

The daemon reads the GGUF header, fits the KV cache into your machine's memory, and advertises the real context to clients — no more “not enough tokens” 400s on small boxes.

🧪 Benchmark harness

A self-contained bench runs real workloads (agent loops, RAG chunks, adversarial prompts) and reports cache-hit rates and end-to-end latency vs. a fresh cache.

🖥️ TUI + web chat

Full-screen terminal chat and a production-ready single-page web UI ship with the package — one command each.

How it works

  1. Boot — toki model use starts llama-server plus the toki daemon, wires your CLI tools at it, and writes the effective context it can actually hold.
  2. Stream — clients call the daemon's OpenAI-compatible API. Shared prefixes hit the cached KV blocks instead of re-running the model.
  3. Persist — toki cache save / toki cache restore snapshot caches to disk; toki cache stats shows hits, misses, and savings.

Quick start

Nothing is preinstalled — you pull exactly what you want. Three commands to first chat:

pipx install tokirecur
toki model install-llama                          # auto-detects ROCm/CUDA/Vulkan/Metal/CPU
toki model pull Qwen/Qwen3-8B-GGUF --name qwen3-8b   # fetch a GGUF, register as "qwen3-8b"
toki model use qwen3-8b                           # boot llama-server + daemon, wire your CLIs
toki tui                                          # full-screen chat — or: toki web

Runs on any x86_64 or arm64 Linux, macOS, or Windows box — with whatever GPU backend your llama-server build has. Optional systemd/launchd daemon mode included.
