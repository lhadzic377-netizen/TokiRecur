Drop-in cache

Point any OpenAI-compatible client at the toki daemon. Prompts that share a prefix return instantly.

Live reuse

Multiple agents and shells share one server's KV cache. Context written by one session is replayed by the next.

Save & restore

Snapshot caches to disk and restore them later: cold-start with a long system prompt already cached, or hand a session to another machine.

RAM-aware by default

The daemon reads the GGUF header, fits the KV cache into the machine's memory, and advertises the real context to clients.

How it works

Three commands from cold start to a shared cache.

Boot the stack, wire your clients at the daemon, and let the prefix matcher do the rest.

  1. Boot, toki model use starts llama-server plus the toki daemon, wires your CLI tools at it, and writes the effective context it can actually hold.
  2. Stream, clients call the daemon's OpenAI-compatible API. Shared prefixes hit the cached KV blocks instead of re-running the model.
  3. Persist, toki cache save / toki cache restore snapshot caches to disk; toki cache stats shows hits, misses, and savings.
Mascot

Meet toki.

toki is the open-source mascot of Toki Recur, the bear who recurs. He wears the recycle symbol because the whole product is one idea: don't recompute what you've already read. Long system prompts, RAG corpora, agent tool definitions, all get computed once, then streamed from cache on every subsequent request.

He's here to remind you that cache reuse is the boring superpower underneath every fast local model.

Quick start

Install in 4 commands.

Nothing is preinstalled, you pull exactly what you want. Clone, install, first chat:

git clone https://github.com/lhadzic377-netizen/TokiRecur.git    # clone the repo
cd TokiRecur                                      # enter it
./install.sh                                      # mac/linux: one installer, yellow progress bar
install.bat                                       # windows: same, one double-click
toki model pull bartowski/Kwaipilot_KAT-Coder-V2.5-Dev-GGUF --use  # pick a GGUF from the list, pulls + activates
toki                                            # opens the launcher: chat, web, models

Runs on any x86_64 or arm64 Linux, macOS, or Windows box, with whatever GPU backend your llama-server build has. Optional systemd/launchd daemon mode included. Platform status: Linux and macOS stable, Windows beta — the Windows installer keeps improving without touching the stable code paths. The installer on macOS/Linux is one script that runs everything behind a yellow progress bar while the real output still streams live.
