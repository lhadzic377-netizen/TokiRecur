Privacy

Nothing here follows you.

This site sets no cookies, runs no analytics, has no accounts, and loads nothing from a third party. What follows is the whole of it, including the parts that are not flattering.

What this site is

A static website for an open-source tool. Every page is a file on a web server. There is no database behind it, no login, and no way for the site to recognise you between two visits.

Cookies and storage

None. No cookies, no tracking identifiers, no advertising or analytics scripts, no fingerprinting. The site loads no third-party code at all: the typeface and the images are served from the same machine as the page, so a request for this page never reaches another company.

What the server writes down

The web server (Caddy) writes its ordinary access log: the client's IP address, the request path, the response status, and the time. That log is used to run the site and to answer abuse. The installer does not configure a retention period, so how long those lines are kept is a decision made on the server rather than by this software. If that matters to you, ask on the issue tracker and the answer will be the truth about that machine.

The chat

The chat app on chat.tokirecur.com is a separate program running on the same machine as this site. When it is running, the prompt you type is sent to the model that is running there. This project does not forward conversations to a model provider, and there is no account system behind it. The chat app may keep its own logs in the usual way a server does.

The software on your machine

The daemon, the terminal UI, and the web UI all run locally. The package talks to the model server you point it at and to the daemon itself. It does not phone home, and it sends nothing to the author of this project. Model weights are downloaded from Hugging Face, or from wherever you point the downloader; those downloads are covered by the provider's own terms.

Links to other places

This site links to GitHub and to Hugging Face. Those services have their own accounts, their own logs and their own privacy policies. What you do there is not covered by this page.

Questions

Open an issue on the issue tracker. It is public, so anything you write there is public. If that is not what you want, say so in the issue and the details can be taken down.
